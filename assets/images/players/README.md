# Player photos

Drop each player's photo in this folder, named **exactly** (all lowercase):

| Player | File name |
|--------|-----------|
| bondeN | `bonden.jpg` |
| Zutch  | `zutch.jpg` |
| tob1   | `tob1.jpg` |
| Hamruz | `hamruz.jpg` |
| Jaybee | `jaybee.jpg` |

(`.png` works too — e.g. `bonden.png`. The card tries `.jpg` first, then `.png`.)

## Tips
- Use a **portrait / square-ish** image — the card crops to a tall portrait focused on the top (faces look best).
- Recommended size: **~800×1000 px** or larger.
- If a photo is missing, the card automatically shows the player's **initial** instead — nothing breaks.

## To publish a photo
1. Save the image here with the correct name.
2. Commit & push (or just tell Claude and it'll commit it for you).
3. Vercel redeploys and the photo appears on the site.
